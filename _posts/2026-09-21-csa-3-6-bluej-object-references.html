这是一份 BlueJ 动手实验。每一步只增加一个新概念： 写一点代码 → Compile → 在 Object Bench 观察 → 画 reference。

整节课只追踪两件事：
① 每次执行 new 时，创建了什么 object？
② 现在有哪些 reference 指向这些 object？

4 Argument 和 Parameter：不是同一个 Variable

这一步不再创建新的 Robot，也不让 target 改指向。我们只把上一步真正发生的事情拆开看清楚。

Method call
profile1.healAvatar(avatar2, 30);

Argument：avatar2

avatar2 是 method 外面已经存在的 variable。它指向 Mage。

Parameter：target

target 是 method 开始运行时创建的临时 variable。method 结束后，它离开 scope。

调用开始时发生什么？

Java 创建 parameter target，并用 avatar2 当前保存的 reference 来初始化它。为了理解，可以把这一瞬间想成：

Conceptual model
Avatar target = avatar2;
注意这不是你需要额外写进程序的一行代码，只是帮助理解 method call 时 parameter 怎样得到初始值。
avatar2 ─────┐
             ├────► Mage (HP 40)
target  ─────┘
最重要的一点：target 不是 avatar2 的另一个名字。它们是两个不同的 variables；只是 method 刚开始时，它们指向同一个 Mage object。

然后执行 target.heal(30)

target 顺着自己的 reference 找到 Mage，并修改这个 Mage object。因为 avatar2 也指向同一个 Mage，所以 method 结束后，从 avatar2 也能看到 HP 已经变成 70。

method 运行时：

avatar2 ─────┐
             ├────► Mage (HP 70)
target  ─────┘

method 结束后：

avatar2 ─────────► Mage (HP 70)
target → 离开 scope
target 存在的意义：
它是 method 内部对“这一次传进来的 Avatar”使用的临时 variable。
因此同一个 healAvatar method 可以处理 avatar1、avatar2 或其他 Avatar，而不需要为每个 object 写一个新的 method。

Reference 的数量和 object 的数量是两件不同的事。

Primitive vs Object Argument

Primitive

score = 80
   │ copy
   ▼
x = 80

parameter 得到 primitive value 的 copy。

Object Reference

avatar2 ───┐
           ├──► Mage
target ────┘

parameter 得到 reference value 的 copy。

两种情况都遵守同一个规则：Java is pass by value.

完整 GameProfile.java
GameProfile.java
public class GameProfile
{
    private String username;
    private int level;
    private Avatar avatar;

    public GameProfile(String u, int l, Avatar a)
    {
        username = u;
        level = l;
        avatar = a;
    }

    public void printProfile()
    {
        System.out.println("Username: " + username);
        System.out.println("Level: " + level);
        System.out.println("Avatar: " + avatar.getName());
        System.out.println("Health: " + avatar.getHealth());
    }

    public void healAvatar(Avatar target, int amount)
    {
        target.heal(amount);
    }


    public Avatar getAvatar()
    {
        return avatar;
    }
}
