这是一份 BlueJ 动手实验。每一步只增加一个新概念： 写一点代码 → Compile → 在 Object Bench 观察 → 画 reference。

整节课只追踪两件事：
① 每次执行 new 时，创建了什么 object？
② 现在有哪些 reference 指向这些 object？

Compare the types

一句话：定义一个 class，也就定义了一种新的 reference type。

Constructor 调用时

constructor 的 parameter a 得到的是 avatar1 中 reference value 的 copy。

调用 constructor 的过程中：

avatar1 ──────────┐
a ────────────────┼──► Knight
profile1.avatar ──┘

Constructor 结束后

avatar1 ──────────┐
                  ├──► Knight
profile1.avatar ──┘

parameter a → constructor 结束后离开它的 scope
Java is pass by value.
这里被复制的 value 恰好是一个 object reference。

修改 Object

Example
target.heal(amount);

调用 method，改变的是 target 指向的 object。

修改 Parameter Reference

Example
target = new Avatar("Robot", 100);

重新赋值，改变的是 local parameter target 自己保存的 reference。

核心区别：
通过 reference 调用 method，可以修改共享 object。
给 parameter 重新赋值，只改变这个 parameter 接下来指向哪里。

Reference 的数量和 object 的数量是两件不同的事。

Primitive vs Object Argument

Primitive

score = 80
   │ copy
   ▼
x = 80

parameter 得到 primitive value 的 copy。

Object Reference

avatar2 ───┐
           ├──► Mage
target ────┘

parameter 得到 reference value 的 copy。

两种情况都遵守同一个规则：Java is pass by value.

完整 GameProfile.java
GameProfile.java
public class GameProfile
{
    private String username;
    private int level;
    private Avatar avatar;

    public GameProfile(String u, int l, Avatar a)
    {
        username = u;
        level = l;
        avatar = a;
    }

    public void printProfile()
    {
        System.out.println("Username: " + username);
        System.out.println("Level: " + level);
        System.out.println("Avatar: " + avatar.getName());
        System.out.println("Health: " + avatar.getHealth());
    }

    public void healAvatar(Avatar target, int amount)
    {
        target.heal(amount);
    }

    public void replaceLocalAvatar(Avatar target)
    {
        target = new Avatar("Robot", 100);
    }

    public Avatar getAvatar()
    {
        return avatar;
    }
}
