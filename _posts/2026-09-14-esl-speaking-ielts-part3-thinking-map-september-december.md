# IELTS Speaking Part 3

Part 3 不要按 **75 道题 = 75 个答案** 来准备。真正需要记住的是：**一道题可以同时连接多个思路。**

<div class="part3-core">
<div class="part3-path">直接回答 → 解释 → 继续发展</div>
<div>Answer → Explain → Develop</div>
</div>

<div class="part3-map">
<div>
<h3>① 考官要你做什么？</h3>
<p><strong>原因</strong>：为什么？有什么影响？<br>
<strong>观点</strong>：你怎么看？重要吗？应该吗？<br>
<strong>比较</strong>：A 和 B 有什么不同？<br>
<strong>变化</strong>：过去和现在有什么变化？<br>
<strong>未来</strong>：以后可能怎样？<br>
<strong>假设</strong>：如果……会怎样？<br>
<strong>解决</strong>：谁可以做什么？</p>
</div>
<div>
<h3>② 答案往哪里展开？</h3>
<p><strong>原因 → 结果</strong><br>
<strong>观点 → 理由 → 例子</strong><br>
<strong>对比 → 原因 → 例外</strong><br>
<strong>方法 → 为什么有效</strong><br>
<strong>过去 → 现在 → 影响</strong><br>
<strong>条件 → 后果</strong></p>
</div>
<div>
<h3>③ 没思路时换谁的角度？</h3>
<p><strong>个人</strong><br>
<strong>儿童 / 青少年</strong><br>
<strong>家庭 / 朋友</strong><br>
<strong>学校</strong><br>
<strong>企业 / 消费者</strong><br>
<strong>政府 / 城市</strong><br>
<strong>社会 / 不同人群</strong></p>
</div>
</div>

> **一句话记忆：Part 3 = 问题功能 × 展开方式 × 思考视角。**

按目前这份题库，没有明显独立的 **未来预测** 或 **假设题**；但“假设”仍然很适合拿来帮助某些抽象题展开。

## 30 秒使用方法

拿到题目后，不要先找“模板句”。先做三个判断：

1. **它让我做什么？** 原因、观点、比较、变化，还是解决问题？
2. **我准备往哪一步发展？** 原因、结果、例子、对比、条件、例外……选一个就够。
3. **还是没想法？** 换一个视角：个人 → 家庭 → 学校 → 企业 / 政府 → 社会。

> 不需要把每个角度都说出来。**找到一个容易解释清楚的角度，就开始回答。**

## 先看 4 个“连接方式”

### 例 1：原因题也可以连接到“假设”

**Why do societies need laws and rules?**

主功能：**原因与因果**  
辅助思路：**反过来想 → 如果没有法律会怎样？**  
视角：**社会 / 政府 / 个人**

> 没有共同规则 → 行为更难预测 → 冲突和不公平增加 → 所以社会需要法律。

### 例 2：解决题要同时连接“方法”和“原因”

**How should children learn about rules and responsibilities?**

主功能：**方法与解决办法**  
展开：**谁 → 做什么 → 为什么有效**  
视角：**家庭 + 学校 + 儿童**

> 家长和学校给孩子真实的小责任 → 孩子看到行为的后果 → 规则不再只是需要背下来的要求。

### 例 3：变化题通常也在考比较

**Are public places more comfortable now than in the past?**

主功能：**过去与现在的变化**  
辅助思路：**比较 → 原因 → 例外**  
视角：**城市 / 居民 / 社会**

> 不要只说 *Yes, they are.* 先选一个比较点：交通、设施、无障碍设计、噪音、绿化等。

### 例 4：观点题经常需要“条件 / 例外”

**Should advertising aimed at children be more strictly controlled?**

主功能：**观点、判断与概括**  
辅助思路：**理由 → 条件 / 例外**  
视角：**儿童 + 企业 + 政府**

> 比起单纯说 *Yes, definitely*，更好的思路是先说明为什么儿童更容易受影响，再考虑哪些广告尤其需要限制。

## 平时怎么练？

不要按主题背答案。每次随机抽 3–5 题，先只做 **5 秒思路判断**：

> **主功能是什么？→ 准备怎么展开？→ 从谁的角度说？**

然后再开口。一个回答只需要把 **一个核心观点解释清楚并再发展一步**，不需要强行凑两个理由。

> **目标不是记住 75 个答案，而是看到新题后，能够迅速找到一条可以走下去的思路。**

### 分类说明

IELTS 官方并没有规定“七大题型”。这里的标签是把 Part 3 长期稳定出现的沟通任务整理成适合课堂训练的框架。**主功能只是最常用的入口，不代表一道题只有一种答法。**
